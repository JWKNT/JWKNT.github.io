Jacobian Conjecture

Short version

A map is a rule that sends each point to a new point. For example, the rule (x,y)→(x+y2,y) sends the point (1,2) to (5,2). This rule is polynomial, because it only adds and multiplies.

A map is reversible if you can always undo it. The map above is reversible: the rule (u,v)→(u−v2,v) sends (5,2) back to (1,2). The map (x,y)→(x2,y) is not reversible. It sends both (1,5) and (−1,5) to (1,5), so nothing can tell you which one you started from.

A map stretches or squeezes small regions. The Jacobian determinant is a number, calculated from the rule at each point, that says how much the area of a tiny region gets multiplied. If it is 2 at a point, tiny shapes there double in area. If it is 0, tiny shapes there are flattened. The map (x2,y) has determinant 2x, so it flattens along the line x=0. That is where it folds over and the two sides collide.

If the determinant is not zero at a point, then the map has no collisions close to that point. But points far apart can still collide. The map (excos⁡y,exsin⁡y) never flattens anything, yet it gives the same output when y grows by 2π. That map is not a polynomial, because it uses e, cosine and sine.

A conjecture is a statement that nobody has proved yet. The Jacobian conjecture said that polynomial maps cannot do this. If a polynomial map has the same nonzero determinant at every point, then it is reversible, and its undo rule is also a polynomial. With one variable this is easy to see, because the map must be cx+d. With more variables the question stayed open.

The conjecture is false with 3 or more variables. Levent Alpöge posted this map and credited the AI model Claude Fable 5. The three lines give the three output numbers:

F1=(1+xy)3z+y2(1+xy)(4+3xy)F2=y+3x(1+xy)2z+3xy2(4+3xy)F3=2x−3x2y−x3z

Its determinant is −2 at every point, so it never flattens anything. Yet three different points have the same output:

F(0,0,−14)=(−14,0,0)F(1,−32,132)=(−14,0,0)F(−1,32,132)=(−14,0,0)

You can check the first line by hand. With x=0 and y=0, the term 1+xy is 1, so F1=z=−1/4. The other two formulas give 0. The second and third lines take more arithmetic, but they are also exact.

Three inputs with one output cannot be undone, so the conjecture fails. To get an example with 4 variables, add a fourth coordinate that the map leaves unchanged. The same step works for any larger number. The case of exactly 2 variables remains open.
