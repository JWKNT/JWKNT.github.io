Unit Distance Problem

Place n points in the plane and count the pairs at distance exactly 1. Let u(n) be the largest possible count. The question is how fast u(n) grows.

A square grid does better than it first appears to. With spacing 1, each point has 4 neighbors. With spacing 1/5, it has 12, because p2+q2=25 has 12 integer solutions. A good choice of spacing gives n1+c/log⁡log⁡n pairs.

Erdős conjectured that this is essentially the best: for each δ>0, u(n) stays below n1+δ for large n. The best known upper limit was a constant times n4/3. So the true exponent lay between 1 and 4/3.

Two results move these limits. An OpenAI model disproved the conjecture: for infinitely many n, some arrangement has at least n1+δ pairs, for a fixed δ>0. It replaces the integers behind the grid with much larger number systems. Later work reached δ=0.043. A later OpenAI manuscript reports that the upper exponent is also below 4/3, by an unstated fixed amount.

n1.043≲u(n)≲nβ,β<4/3

The exact exponent remains unknown.
