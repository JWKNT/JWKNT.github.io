Exponential Time Hypothesis

Simplify

3-SAT asks if a logical formula can be made true by setting each variable to true or false. Each bracket, or clause, has at most three items:

(a∨b∨¬c)∧(¬a∨c∨d)∧⋯

Here ∨ means "or", ∧ means "and" and ¬ means "not". With n variables there are 2n settings, so testing them all doubles the work with each new variable. Better algorithms multiply the work by about 1.308 per variable, but the time stays exponential.

The Exponential Time Hypothesis says that this multiplier cannot come arbitrarily close to 1. Some constant c>1 exists such that every algorithm needs at least cn steps on the worst formulas. This is stronger than P≠NP, which only excludes polynomial time. Researchers use the hypothesis to show that many other problems are hard.

OpenAI and Anthropic each report that it is false. Each gives an algorithm that counts the solutions in the time on the last row of the table. That exponent is a constant times n times log⁡log⁡n/log⁡n, and this last factor falls to zero as n grows. So the multiplier per variable falls toward 1, and no constant c can work.

The gain exists only for enormous inputs. Anthropic calculates that its bound beats 2n only above n=1010000, on formulas with 5n clauses. P versus NP stays open, because this time is still far above any polynomial.
