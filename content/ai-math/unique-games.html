A unique game is a system of equations of the form \(x_i - x_j = c\), with arithmetic modulo a fixed number. Each equation has two variables, so a value for one variable fixes the other.

If all the equations can hold, a solution is easy to find. Choose one value and follow the equations. If only 99% can hold, this method fails. A chain of 100 equations has a wrong equation with probability 63%, and each value after it is wrong.

The Unique Games Conjecture says that this difficulty is real and extreme. When 99% of the equations can hold, it is NP-hard to find values that satisfy even 1% of them, if the modulus is large enough. The same holds with any numbers near 100% and 0% in place of 99% and 1%.

An OpenAI manuscript reports a proof. It turns any 3-SAT formula, in polynomial time, into a game. If the formula has a solution, nearly all equations can hold. If not, almost none can.

The conjecture implies that many known approximation algorithms are the best possible unless \(\mathrm{P} = \mathrm{NP}\). For example, no fast algorithm can guarantee a graph cut above 0.878 of the largest cut, or a vertex cover below twice the smallest.
