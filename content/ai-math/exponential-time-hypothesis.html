3-SAT asks if a logical formula can be made true, where each bracket has at most three items:

\[ (a \lor b \lor \lnot c) \land (\lnot a \lor c \lor d) \land \cdots \]

With \(n\) variables, testing every assignment takes \(2^n\) steps. Better algorithms reach about \(1.308^n\), but the time stays exponential.

The Exponential Time Hypothesis says that this cannot be avoided. Some constant \(c > 1\) exists such that every algorithm needs at least \(c^n\) steps on the worst formulas. This is stronger than \(\mathrm{P} \ne \mathrm{NP}\), which only excludes polynomial time. Researchers use the hypothesis to show that many other problems are hard.

OpenAI and Anthropic each report that it is false. Each gives an algorithm that counts the solutions in the time on the last row of the table. The factor \(\log\log n / \sqrt{\log n}\) falls to zero as \(n\) grows. So the exponent eventually falls below \(\delta n\) for every \(\delta > 0\), and no constant \(c\) can work.

The gain exists only for enormous inputs. Anthropic calculates that its bound beats \(2^n\) only above \(n = 10^{10\,000}\), on formulas with \(5n\) clauses. P versus NP stays open, because this time is still far above any polynomial.
