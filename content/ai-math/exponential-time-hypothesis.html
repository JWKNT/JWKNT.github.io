The Exponential Time Hypothesis says that 3-SAT, a basic logic problem, needs exponential time in its worst cases. OpenAI and Anthropic each report an algorithm that is faster than every exponential for large inputs. The algorithms give no practical speed gain.

{{facts}}

The question

A Boolean variable has the value true or false. A clause joins variables or their negations with "or". A 3-SAT formula joins clauses of at most three items with "and". An assignment gives a value to each variable. A solution is an assignment that makes every clause true.

The 3-SAT problem asks if a formula has a solution. Many scheduling, design and verification problems can be written as 3-SAT. The question for this result is how fast an algorithm can answer for the worst formulas.

The formula has a solution, and it has exactly four solutions. To answer "is there a solution" and to answer "how many solutions" are different tasks. Counting is at least as hard.

Exhaustive search tests every assignment. A formula with \(n\) variables has \(2^n\) assignments, so each extra variable doubles the work. With 100 variables there are about \(1.27 \times 10^{30}\) assignments. A computer that tests \(10^{18}\) assignments each second needs about 40,000 years.

Better algorithms exist. Before October 2026, the fastest known randomized algorithm used about \(1.308^n\) steps. The fastest known deterministic algorithm used about \(1.328^n\) steps.

The hypothesis

Russell Impagliazzo and Ramamohan Paturi stated the Exponential Time Hypothesis, and a paper of 2001 gives its usual form. It says that a number \(\delta > 0\) exists such that no algorithm solves every 3-SAT formula in \(2^{\delta n}\) steps. Thus the base of an exponential time cannot come arbitrarily near 1.

The hypothesis was a working assumption and not a theorem. In a 2012 lecture, Impagliazzo said that he and Paturi gave it about even odds of being true.

Researchers used the hypothesis to explain why other problems appear hard. If a fast algorithm for problem \(X\) gives a fast algorithm for 3-SAT, then the hypothesis limits the speed of any algorithm for \(X\).

{{divider}}

The result

A k-CNF formula is the same as a 3-SAT formula, except that each clause has at most \(k\) items. The OpenAI paper states a deterministic algorithm that counts the solutions of a k-CNF formula with \(n\) variables and \(m\) clauses. For each fixed \(k\), it uses polynomial space and this time:

\[ (n + m)^{O_k(1)} \cdot 2^{\,O_k\left(n \log\log n \,/\, \sqrt{\log n}\right)} \]

The notation \(O_k(x)\) means at most a constant times \(x\), where the constant depends only on \(k\). The Anthropic paper states a time with the same main term. Its constant is explicit in \(k\), and it also gives a bound in terms of \(m\).

The exponent is \(n\) times a factor \(c(n) = \log\log n / \sqrt{\log n}\). This factor goes to zero as \(n\) grows. So for each \(\delta > 0\), the time is below \(2^{\delta n}\) when \(n\) is large enough, and the hypothesis is false.

What the result does not say

  • It does not settle P versus NP. The new time is still far above any polynomial. Both groups say that their result does not settle that question.
  • It does not speed up every NP problem. A general reduction to 3-SAT can raise the variable count from \(n\) to \(n^2\) or more. A time of \(2^{o(n)}\) in the old variable count does not stay subexponential after that change.
  • It does not help with real formulas. Anthropic calculates that its bound for formulas with \(m = 5n\) beats exhaustive search only for \(n > 10^{10\,000}\). Its bound in \(n\) alone needs \(n > 10^{10^{8}}\). Exhaustive search is already impractical at \(n = 100\).
  • It does not remove all related lower bounds. Many of them also follow from the Orthogonal Vectors hypothesis, and this result does not refute that hypothesis.

Why the result matters

Many hardness results rest on this hypothesis. Anthropic searched the literature with Claude and found more than 800 papers. Each has a result that holds only under this hypothesis or a stronger one. If the proofs hold, those results lose that support. They do not automatically become false.

The Strong Exponential Time Hypothesis and Gap-ETH imply this hypothesis, so the same proofs refute them. The OpenAI paper also refutes the nondeterministic form of the strong hypothesis.

The result also gives new subexponential algorithms in theory. They count independent sets, proper colorings and perfect matchings in a graph. They also solve Independent Set, Clique, Vertex Cover and Dominating Set in \(2^{\delta n}\) steps for every \(\delta > 0\).

How far the result has been checked

OpenAI states that its model found the argument on 16 October 2026 and that the Lean proof followed on 17 October. Its Lean proof gives a slightly weaker exponent, with \((\log\log n)^2\) in place of \(\log\log n\). That weaker exponent still refutes the hypothesis.

Anthropic states that an internal Claude model found its core algorithm on 16 October, with no human input and independently of OpenAI. Its repository holds a Lean proof, checked by a second, independently written proof kernel. The repository warns that no machine checks whether the Lean file says what the paper says. It keeps the file short for human readers.

OpenAI states that a group led by Impagliazzo, Paturi and Ryan Williams will verify and explain its result. The reviewers state that their part in this examination is not a certification. No source reports a finished journal review on this date.
