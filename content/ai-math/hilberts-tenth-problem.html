Hilbert asked for an algorithm that takes any polynomial equation with integer coefficients and decides if it has a solution. His question asks for solutions in integers. The new result concerns solutions in fractions.

A search can find a solution if one exists, but it can never answer "no", because it would have to test infinitely many candidates. Solutions can also be enormous, as the table shows. So the question is whether a better method always gives the right answer.

For integers, the answer has been no since 1970. Polynomial equations can encode programs: each program has an equation with an integer solution exactly when the program stops. An algorithm for equations would then solve the halting problem, which is impossible.

For fractions, that argument does not transfer directly, because the encoding needs integer solutions. An OpenAI preprint reports that the answer is still no. No algorithm can decide, for each polynomial with integer coefficients, if it has a rational zero. This holds even for polynomials of degree at most 4. Each single equation still has a definite answer, but no single program gets all of them right. A later manuscript reports a more direct route.
